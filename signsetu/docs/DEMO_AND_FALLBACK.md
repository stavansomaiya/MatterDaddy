# Demo script (≈80 s), screenshots, fallback plan

## Before you start
Server running, page open at http://localhost:8000, **Hospital**, **English**, volume up, camera not yet started.
Use only signs that passed checklist B3 under the venue's lighting. The script below assumes `palm`, `horns`, `ell`, `pinky`.

## Script
| Time | Say | Do |
|---|---|---|
| 0:00 | "Deaf and hard-of-hearing people often can't be understood at a hospital or bank counter, and staff don't know sign language. SignSetu is a bridge." | Point at hero banner |
| 0:10 | "The browser reads 21 points on the hand with MediaPipe, our Python backend recognises the sign, and the page shows big text and says it aloud. No video leaves the machine." | Point at **Backend on** pill, press **Start camera** |
| 0:22 | "Open palm." | Show 🖐️ → "Hello" appears and is spoken. Mention the yellow bar = hold-steady safety |
| 0:30 | "At a hospital this shape means…" | Show 🤘 → "I need a doctor. I need help." |
| 0:40 | "The same shape at a bank…" | Click **Bank**, show 🤘 again (lower hand first) → "I need help with my account." "Context-aware." |
| 0:52 | "And in Hindi." | Click **हिन्दी**, show 💧 pinky → "कृपया मुझे पानी चाहिए" spoken in Hindi |
| 1:02 | "Staff can answer back in large text." | Type "Please sit. Help is on the way." in Reply → **Show reply** (or use the mic) |
| 1:12 | "It only speaks a sign once it's held steady, ignores unknown shapes, and keeps working if the backend drops." | (Optional) show a random hand shape → silence |
| 1:20 | "Today it recognises 13 hand shapes with geometric rules — next step is a trained ISL model on a real dataset." | Close |

**Honesty line for Q&A:** "It's rule-based on landmarks, 13 static shapes, not full ISL. We chose to be accurate about that."

## Fallback plan (use the first that applies)
| Failure | Do this |
|---|---|
| Backend crashes / port busy | Do nothing — page falls back to browser rules (pill "Backend off"). Mention it as a feature. Restart server afterwards if time allows |
| Camera won't start / permission | Use **Sign guide** cards: clicking runs the same text + speech path. Say "camera-free mode for kiosks" |
| Webcam works but recognition is flaky | Switch to the two or three most reliable signs; use the dictionary cards for the rest |
| No Wi-Fi | Nothing to do: MediaPipe is bundled locally. Only a browser without camera access needs the dictionary cards / backup video |
| No Hindi voice | Demo Hindi *text* only, or stay in English |
| Speakers silent | Text still shows; say what was spoken; check Voice on and system volume |
| Everything dead | Play backup video, walk through screenshots |

Rule: whoever drives the demo never debugs on stage — a second member switches to the fallback.
